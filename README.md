## Как читать

- Нужен быстрый ответ — `01`.
- Нужен рабочий обзор для чата — `02`.
- Нужен подробный разбор — `03`.
- Нужен полный архивный документ — `04`.
- Нужно понять, что пошло не так — `05`.
- Нужно продолжать поиски — `06`.
- Нужны тексты для людей — `07`; официальные письма в архивы — `08`.
- Нужен общий список кандидатов — `10` (таблица) или `candidates.csv` (данные).
- Нужна калибровка скорости и готовый исправленный файл — `11` и `Розовый_Кадиллак_CD-speed_r1055.mp3`.
- Нужно понять, годится ли старая оцифровка для сравнений — `12`.
- Нужен разбор помехи 15,7 кГц — `13`.
- Нужны свежие сообщения из живого чата — `14`.

## Важное ограничение

Документы фиксируют статус на 12.11.2026. Часть ответов кандидатов известна только по скриншотам и пересказам; статусы «опровергнуто» означают «по имеющимся данным, скорее не она», а не юридически доказанный факт. Отрицательные результаты РАО/ГТРФ не доказывают, что песня не звучала.
