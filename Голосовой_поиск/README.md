- **Ольга Климентьева** проверена по 11 современным песням: максимум 0.4675 (UVR + ECAPA), ниже positive controls и известных не-таргетных голосов. Голосового совпадения нет; 22.11.2026 Игорь написал ей, ответа пока нет — нужны ранние записи 1990-х.
- **Татьяна «Марго» Кокоулина** проверена по 4 трекам: максимум 0.3892 (UVR + ECAPA), ещё ниже positive controls. Если «Твой поцелуй» — оригинал 1994 г., версия не подтверждается.

Голосового совпадения нет; контекстный след Омска/1991 сохраняется, но приоритет низкий.
