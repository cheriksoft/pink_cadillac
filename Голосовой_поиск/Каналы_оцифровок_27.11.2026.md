## 3. Как массово сканировать

### Этап 1 — короткие треки

Каналы: **MUSIC ARCHIVE**, **Алексей Ищенко**, частично **MurZone**.

1. Получить список видео через `yt-dlp` (flat, без скачивания).
2. Оставить длительность 2–10 минут; отбросить клипы, интервью, обзоры.
3. Скачать только аудио в низком битрейте (64–96 kbps).
4. Прогнать 8-секундные окна с шагом 2 секунды через ECAPA и четыре target-варианта.
5. Зафиксировать: канал, video_id, title, timestamp, score, variant.
6. Отобрать top-30 и только для них делать UVR/Demucs.

Ожидаемый объём: **~60 видео / 4 часа аудио** — один-два прогона.

### Этап 2 — полные альбомы

Каналы: **Песни моей молодости**, **Стихия музыки**, **Audio БАГаж**, **Профессор фон Кляйсер**, **МагнитИздат**, **Черный Ярл**.

1. Скачать альбом целиком (audio-only).
2. Если есть главы/треклист — нарезать по трекам.
3. Если треклиста нет — скользящие 60-секундные фрагменты с шагом 30 секунд.
4. Считать ECAPA по каждому фрагменту; сохранять top-10 фрагментов на альбом.
5. Для top-фрагментов — UVR/Demucs и прослушивание.

Ожидаемый объём: **~90 альбомов / 50–90 часов аудио**. Начинать не со всех, а с 3 каналов:
**Песни моей молодости → Стихия музыки → Audio БАГаж**.

### Этап 3 — проверка

- UVR + Demucs + ECAPA на top-кандидатах.
- Сравнение с positive controls и известными ложными кандидатами.
- Ручное прослушивание 15-секундных фрагментов.
- Не считать высокий score доказательством: это только ранжировщик.

## 4. Ограничения

- AI-реставрации и «улучшенные» версии меняют тембр; для голосового поиска их лучше исключить.
- Полные альбомы без треклиста трудно нарезать; возможны дубли и склейки.
- YouTube может отдавать 403 на отдельные видео; нужен retry.
- Не все каналы перечислены: всего в первичной выдаче было **102 канала**, в каталог включены только релевантные.
- Массовая выкачка не должна превращаться в склад видео: храним только аудио и результаты скана.
