## 1. Что это за документ

Здесь описан метод автоматического поиска исполнительницы «Розового Кадиллака» по тембру голоса и собраны кандидаты, которые прошли первичный отбор.

Это **не список доказанных совпадений**. Скор — это мера акустического сходства, а не вероятность того, что это та же певица. Финальное решение — только после прослушивания человеком.

## 3. Метод

### 3.1. Первый проход: сырой микс

Для каждого кандидата:

1. Скачивается аудио.
2. Берутся 6 окон по 8 секунд по всей длине трека.
3. Считаются эмбеддинги ECAPA-VoxCeleb по **сырому миксу**, без разделения.
4. Сравнение с четырьмя target-вариантами: raw, fast105, fast110, CD.
5. Фиксируется лучший скор и вариант, на котором он получен.

Это дешёвый фильтр: не нужно гонять UVR по всей библиотеке.

Проверка метода на контрольных парах дала AUC ≈ 0.917 для «тот же / другой вокалист» даже на сыром миксе. Этого достаточно для отбора, но не для идентификации.

### 3.2. Второй проход: вокал

Для топ-кандидатов:

1. Полный трек разделяется `UVR-MDX-NET-Voc_FT` на GPU.
2. Из вокальной дорожки выбираются 8-секундные окна с активным вокалом.
3. Считаются эмбеддинги ECAPA.
4. Сравнение с четырьмя **вокальными** target-вариантами.
5. Считается медиана косинусного сходства и отрыв от второго варианта.

### 3.3. Ограничения

- Модель ECAPA обучена на речи, а не на пении.
- Старые записи, шум, реверб и разделение вокала искажают тембр.
- Разные источники дают разные абсолютные скоры.
- Модель может путать стиль/эпоху/продакшн с голосом.
- Поэтому ранжирование — только фильтр для прослушивания.

## 4. Тест метода: сам «Розовый Кадиллак» на Magnitizdat

На канале Magnitizdat нашлись две загрузки самого target:

| Видео | Ссылка | Raw-скан | Вокал |
|---|---|---:|---:|
| «Розовый кадиллак (1991)» | `https://www.youtube.com/watch?v=Md_997OFI1k` | 0.6766 | **0.6341** |
| «Розовый Кадиллак (Lostwave)» | `https://www.youtube.com/watch?v=PiYpT8S5Ycc` | 0.6566 | **0.5451** |

Это **positive control**: метод действительно поднимает target наверх. Но разброс между двумя загрузками — 0.6341 и 0.5451 — показывает, что абсолютный порог ненадёжен. Всё, что ниже 0.545, уже нельзя считать «похоже» без прослушивания.

### Комментарии

- **Оксана Соколова** — ближе всех к нижнему positive control (0.5367 против 0.5451). Лучший вариант — `fast110`, то есть есть слабый признак того, что исходный вокал мог быть замедлен.
- **«Четверть века»** — высокий отрыв от второго варианта (margin 0.0835) и лучший результат на `raw`. Это может быть устойчивее, чем просто высокий скор.
- **«Двое»** — лучший на `fast110`.
- **Ирина Турган** — лучший на `raw`.
- **Анна Бекренева** — лучший на `fast105`.
