# Архивы: веб-архив и архивные каталоги

**Дата:** 19.11.2026  
**Назначение:** отдельный каталог для поисков в веб-архивах, старых интернет-каталогах и архивных базах. Голосовой поиск и аудиофорензика остаются в `../Голосовой_поиск/`.

## Материалы

| Файл | Что внутри |
|---|---|
| `Веб-архив_Омска_15.11.2026.md` | Проверка первых омских интернет-порталов 1997–2003 гг. (`omsk.ru`, `omsk.com`, `omsk.net.ru`, `omsknet.ru`, `omskcity.com`, «Омские страницы», «Город мастеров»). Следов сайта «Пирамида-Арт» нет; есть новые имена сессионных вокалисток. |

## Что сюда относить

- поиски по Wayback Machine, CDX и старым каталогам сайтов;
- архивные каталоги релизов, лейблов и студий;
- подшивки газет и журналов, если они оцифрованы;
- описания фондов ГТРК, ГТРФ, РГАФД и местных архивов.

## Что не сюда

- тембральные эксперименты, ECAPA, UVR и аудиосэмплы — в `../Голосовой_поиск/`;
- обновления Telegram-чата — в корне `output/`.
